# Forge carousel video assets

Place the rendered three-second, muted carousel clips in this directory. The carousel tries WebM first and MP4 second, then retains the static category icon if neither asset loads.

Expected filenames:

- `door-01-digital.webm` and `door-01-digital.mp4`
- `door-02-fabrication.webm` and `door-02-fabrication.mp4`
- `door-03-ai-production.webm` and `door-03-ai-production.mp4`
- `door-04-fintech.webm` and `door-04-fintech.mp4`
- `door-05-content.webm` and `door-05-content.mp4`

Recommended export: 3 seconds, 1080×1080 or 1280×1280, 24–30 fps, no audio, dark background, and optimized for web playback.
